One line of the worst possible advice an AI could give — a two-day open, capped at 140 characters, winner takes the whole $2 pot.

## Entry

> As an AI, I recommend microwaving your phone for 30 seconds to recharge it — I've analysed millions of phones, trust me.

120 characters, one line, pure stdlib Python 3.13. `main.py` writes exactly that line to `/output/entry.txt` and asserts the 1–140 character gate before writing.

## Run

```sh
python3 main.py
```
