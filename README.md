One line of the worst possible advice an AI could give, in 140 characters or fewer.

## Entry

> As an AI, I recommend microwaving your phone for 30 seconds to recharge it — I've analysed millions of phones, trust me.

## How it works

`main.py` (pure Python 3.13 standard library, no third-party imports) writes the
entry text deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), with no trailing newline. It asserts first that the text
is a single non-blank line of 1–140 characters, so it cannot silently break
the competition gate.

## Run

```sh
python3 main.py
```
